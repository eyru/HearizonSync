## 一、项目概况

| 项目 | 内容 |
|---|---|
| 名称 | Hearizon Sync（Hear + Horizon + Sync） |
| 定位 | Windows 桌面端实时字幕翻译：麦克风采集 → 本地识别 → 翻译 → 双栏字幕 |
| 作者 | 何瑞程（北京语言大学 海南国际学院，听力与言语康复学） |
| 仓库 | https://github.com/eyru/hearizon-sync |
| 许可 | GPL-3.0 + 商业许可（双许可） |
| 分发 | 单文件安装包（NSIS），内置 Python 运行时与两个模型，约 367 MB |
| 技术栈 | sherpa-onnx / SenseVoice-Small、CTranslate2 + opus-mt、faster-whisper、faster-whisper、sounddevice、Tk（全自绘控件）、PyInstaller、NSIS |

核心理念：**识别全部在本机完成，音频不出本机；翻译提供三条互不干扰的路线，由使用者自己选择。** 程序不替使用者决定花钱与否，也不在后台借用其它软件的凭据。

### 各阶段要点

**v1.0.x — 打通链路。** 目标只有一个：说一句，屏幕上出现一句翻好的中文。此阶段确定了两条底层约束：识别用 SenseVoice（ONNX，不需要 torch），翻译用 opus-mt（CTranslate2）。这一阶段踩到的坑：图标与协议编码、窗口模式启动崩溃。

**v1.1.0 — 小语种互译计划。** 起点是朱睿杰（北京语言大学）的提议：只做英译中覆盖面太窄。于是加入输入语言选择，把 Whisper 接入补齐德/法/意/西，日/韩也交给 Whisper。同一版本发现关键事实：本版 sherpa-onnx 的 SenseVoice `language` 参数实测无效，日韩会被稳定误判，只能换引擎绕开。

**v1.2.0 / v1.3.0 — 从"能用"到"像软件"。** 字幕样式、快捷键、SRT 导出、无声提醒、首次引导；随后补托盘、真实时间轴、配色与贴底/贴顶。v1.3.0 未单独发版。

**v2.0.1 — 界面推倒重做。** Tk 原生控件全部替换为自绘：圆角按钮、圆角复选框、自绘下拉弹层、现代滚动条、可滚动侧栏；同时启用正式中文 EULA。

**v2.1.1 — 自动纠错，同时埋下两处隐患。** 在识别后、翻译前插入最小修正层（本地词表 + 云端 LLM 兜底），用于处理"声级计/升级计"这类同音错字。此版本同时埋下两个未被发现的问题：GPU 失败提示文案写死；API Key 会读取机器上其它软件目录下的凭据。原因很直接——只在开发机上测过。

**v2.2.x — 云端接入的内部迭代（未单独发版）。** 该阶段翻译行为不稳定，反馈集中在"有时候翻、有时候不翻"。内部采取反复重试与自动降级，降级链越堆越复杂，反而无法解释实际走了哪条路。此阶段未对外发版。

**v2.5.1 — 结构性重构与最彻底的一次检修。** 详见第三节。

## 三、v2.5.1 专项记录

### 3.1 需求来源

1. 版本号升级至 v2.5.1。
2. 修复"没有 NVIDIA 显卡却提示已检测到显卡"的文案问题。
3. 翻译能力整合为三条独立路线：本地 / 在线翻译 / DeepSeek 与有道 API 接入；其中在线翻译必须完全免费、能在任何电脑上运行，不依赖翻墙。
4. 删除 auto 模式；选定模式后，该模式不可用的语言置灰且不可选；API 模式必须由使用者显式选择。
5. 选中 API 模式时，状态栏显示「API模式启动，auto功能失效」，并自动开启自动纠错。
6. 其它模式下勾选自动纠错时，提示会消耗 API 余额，并提供「不再提醒」。
7. 不得破坏既有彩蛋（开发者名片、诗词、关于页连点版本号）。
8. 依赖一律打包进安装包（宁可体积大，不可功能残）。
9. 后续追加：彩蛋 4——在 API Key 输入框输入「致谢名单」弹出致谢页。

### 3.2 免费翻译接口调研（实测）

目标：不注册、不绑卡、不用代理，在中国大陆家用宽带上直接可用。

| 接口 | 大陆直连 | 实测结论 |
|---|---|---|
| MyMemory | 可以 | 18/18 句全成功；英→中/日/韩/德/法/西/意、中→英/日 整句质量可用 |
| 有道免费网页接口（aidemo） | 可以 | 仅支持译成中文；1.2 s 间隔连发 18 句，前 6 句成功，其余全部 `411`；冷却 65 s 后恢复；1 次/10 s 节奏 6/6 通过 → 约 6 次/分钟 |
| Google 翻译接口 | 不可达 | 境内需代理，按需求直接排除 |
| 金山 iciba 旧接口 | 可以 | 已下线，返回 HTML，不可用 |

结论：采用**单一免费引擎 MyMemory**，并在其外层建立全程免费的兜底链。

额度（依据 MyMemory 官方文档）：匿名 5000 字符/天；提交有效邮箱（`de` 参数）提升至 50000 字符/天。折算约 30~40 分钟 / 5~6 小时连续讲话。

### 3.3 实现要点

- **三种模式**：本地翻译（离线，仅英→中）、在线翻译（免费）、API 模式（付费）。三者互不降级。
- **语言可用性矩阵**：本地模式仅放行「自动检测 / 英语」→「中文」；其余模式放开全部语言。下拉框新增禁用项支持，不可用语言变灰且点击无效，当前选择自动纠正到可用项。
- **免费在线引擎**：MyMemory 为主（多目标语言）→ 有道免费为中文兜底 → 本地 opus-mt 为最终兜底；含结果缓存、按日额度记账（写入 `~/.hearizon_sync.json`）、限频与冷却。
- **API 模式**：DeepSeek 流式优先，有道智云次之；不降级到本地。选中时状态栏固定文案并强制开启自动纠错。
- **Key 来源**：仅环境变量 `DEEPSEEK_API_KEY` 与设置页（配置文件）。已删除读取 DSH 凭据的逻辑。设置页新增 DeepSeek Key 输入与 MyMemory 邮箱（可选）。
- **GPU 探测**：改为三路判断（`ctranslate2` CUDA 设备枚举 / `nvidia-smi` 存在性 / WMI 显卡列表），`cuda_probe()` 返回三元组（是否可用、说明、是否真有 N 卡）；无卡与有卡缺运行时使用两套不同文案。
- **打包**：模型纳入 PyInstaller 数据，落在 `_internal/models/`；新增 `sys._MEIPASS` 模型查找路径（`_bundle_dir()`），保证安装目录与打包目录都能命中。
- **彩蛋 4**：任意 API Key 输入框输入「致谢名单」弹出致谢页，名单 9 人。

## 五、已知限制与待办

**已知限制**

- 非真·同传：说出来一句译一句，端到端延迟 1~2 秒。
- 本地翻译仅覆盖英→中（opus-mt 为单语言对模型）。
- 日/韩识别走 Whisper（本版 SenseVoice 的 `language` 参数无效）。
- 免费在线受每日额度限制（5000 / 50000 字符）。
- 能量 VAD 不区分说话人，重叠语音会合并。
- 仅支持麦克风输入，系统声音需 VB-Cable 等虚拟声卡。
- 非医疗器械，不得用于听力诊断或医疗用途。

**待办**

1. 安装包的**真实安装验证**尚未完成——执行环境非管理员，无法静默安装；目前仅有 CRC 校验与解包目录验证。需在管理员环境双击安装并跑一次完整同传。
2. 免费接口长期可用性需持续观察；MyMemory 若政策变化，需切换兜底顺序。
3. 实时翻译在免费路线下的端到端延迟（含网络往返）尚无正式基准数据，建议补测。
4. 版本历程中 v2.2.x 的口径如需调整（补 tag 或改写），需与发布记录同步。
